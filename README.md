A pure Bash security inspection tool  
**Fast • Read-only • Non-destructive • Open-source**  
Crafted with ☕ & 🖤 by MR.Thugh

## 🚀 Features

- 🔍 HTTP Security Header Inspection
- ⚡ Fast & lightweight (Pure Bash)
- 🐧 Linux native (no dependencies)
- 🛑 Read-only (no exploitation, no abuse)
- 🎨 Hacker-style CLI output

## 📦 Installation

```bash
git clone https://github.com/MRThugh/BashSpecter.git
cd BashSpecter
chmod +x bashspecter.sh
```

## 🧪 Usage

```bash
./bashspecter.sh example.com
```

or:

```bash
bash bashspecter.sh example.com
```

## 🧠 How It Works

BashSpecter sends safe HTTP HEAD/GET requests to inspect common security headers:

- `Content-Security-Policy`
- `X-Frame-Options`
- `X-Content-Type-Options`
- `Strict-Transport-Security`
- `Referrer-Policy`

✔️ No data modification  
✔️ No brute force  
✔️ No vulnerability exploitation
